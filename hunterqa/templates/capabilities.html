Operational local components

Semgrep: bundled offline rules for selected Python, JavaScript/TypeScript and PHP patterns. Actual findings depend on installed Semgrep.

Configuration: deterministic checks of Dockerfiles, Kubernetes YAML and Terraform configuration.

OpenAPI: offline JSON contract checks for missing declared security requirements.

Dependencies: offline inventory; exact-version known-advisory matching only if the user supplies a local advisory snapshot.

CodeQL: read-only SARIF import. CodeQL CLI is an optional external installation.

Fuzzing: AFL++ harness guidance and an explicitly authorized CLI crash replay in an isolated VM.

Runtime: ASan/UBSan parsing, reproducibility checks, source evidence and conservative correlation.

AI: local Ollama-assisted triage, with all generated conclusions marked as unverified.

Approved assessment CLI: expiring plans and explicit plan-fingerprint approval for exact HTTP observations, benign WAF canaries, one designated-account HTTPS login, or narrow remote browser form review with JavaScript disabled. Request budgets and stop-file controls apply per invocation. Results require analyst review.

Reviewed handoff CLI: prepare disclosure and CVE request packages from analyst-validated dossiers. Packages are private drafts; nothing is sent and no CVE is assigned.
