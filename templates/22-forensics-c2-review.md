# HunterQA — private Forensics & C2 worksheet

Copy outside this repository. Never commit completed copies, client logs, names,
addresses, domains, accounts, commands, credentials, tokens or payloads.

1. Record owner authorization, evidence scope/source, approved maintenance/test
   baseline, collection date, reviewer and preservation/custody references.
2. Evidence preservation: independently review retention, central collection,
   tamper alerts, time integrity, immutable storage, custody and incident evidence
   procedures. A saved event or a hash does not independently prove integrity.
3. Authorized-framework governance: review actual framework inventory, operator
   access, network isolation, transport visibility, domain/egress restrictions,
   session audit, revocation and approved cleanup records.
4. Fill JSON observations: true = supported assurance review, false = assurance
   gap, null = unassessed. Keep supporting private references here only.
5. Optionally review saved Windows event XML or Zeek DNS JSONL. Record unknown
   fields, unsupported elements/rows, mismatched event context and DNS threshold
   rationale. TXT/long queries and audit/time changes can be legitimate.
6. Independently correlate endpoint/network/central log evidence and approved
   changes; do not infer malicious tampering or a C2 framework from metadata alone.
7. Document remediation owner and authorized retest. Preserve originals and keep
   real-world effectiveness unverified.
