# HunterQA — private Supply Chain worksheet

Copy outside this repository. Never commit completed copies, private package/scope
names, source URLs, accounts, credentials, tokens, scripts or client identifiers.

1. Record owner authorization, local evidence scope, provenance, review date,
   reviewer and the approved artifact/source/integrity baseline.
2. Review actual dependency inventory, artifact provenance and bytes, signatures,
   maintainer/release access, install-script policy, build isolation and verification.
   Saved digest syntax or metadata is not proof of authenticity.
3. Review private namespace ownership, source/scope mapping, credential scoping,
   package-manager version and actual CLI/environment/config precedence. Multiple
   indexes are not a private-first isolation boundary; no public-name probes are run.
4. Fill JSON observations: true = supported assurance review, false = assurance
   gap, null = unassessed. Keep supporting private references here only.
5. Optionally review saved npm lock v2/v3, npmrc or pip INI. Record unknown fields,
   unsupported settings, interpolation and link/alias/workspace/context limits.
6. Independently triage every candidate against actual use and approved policy;
   do not infer compromise, dependency confusion, CVEs or trust from static settings.
7. Record remediation owner, evidence and authorized retest. Keep real-world
   effectiveness unverified and preserve original configuration copies privately.
